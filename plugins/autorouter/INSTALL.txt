KiCad Autorouter 0.3.0

Install or update from this ZIP
1. Open the KiCad project manager and choose Plugin and Content Manager.
2. Choose Install from File and select kicad-autorouter-0.3.0.zip.
3. Apply pending changes, then restart the PCB editor or refresh its plugins.
4. Open Tools > External Plugins > Autorouter (or its toolbar button).

Requirements
KiCad 9 or 10, using the SWIG action-plugin API. The built-in router requires
no external routing program or AI account. The optional AI assistant requires
a separately installed and authenticated Codex CLI.
Validated for this release on KiCad 10.0.7 on macOS.

Using the router
Save a copy of your board, open Autorouter and choose Route. By default it
keeps existing copper and routes open connections. Review the saved board
with KiCad DRC after routing. Connectivity and clearance checks do not replace
signal-integrity or manufacturing review.

Changes in 0.3.0
- Signal via clearance uses barrel-sized maps instead of double inflation.
- Isolated copper is repaired after signal and power routing.
- Temporary keepouts account for track and via copper footprints.
- Fine-pitch via-site protection and connected-plane landing repairs.
